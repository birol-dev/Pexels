StockFinder AI pricing

The app is free forever under the MIT license. You bring your own API keys. There is no StockFinder subscription and no paid tier.

Last updated August 18, 2026

$0

App license · MIT open source · Windows, macOS, and Linux

What you pay for

StockFinder AI itself has no cost. Download it from GitHub, use it, fork it. The only usage costs come from providers you already choose:

LLM provider (required for AI beat mapping)

  • OpenAI — pay per token (typically cents per script run)
  • Google Gemini — pay per token (typically cents per script run)
  • OpenRouter — pay per token; unlocks Claude, Qwen, and other models

You choose the provider and model. Keys stay in your OS keychain. See the privacy page.

Pexels API (required for stock search)

  • Price: $0 — free developer API
  • Limits: Pexels monthly quota, tracked in-app
  • Sign up: pexels.com/api

What is included

There is only one tier. Everything ships in the free app:

  • Script-to-beat AI parsing
  • Pexels photo and video search
  • Organized local downloads (photos/, videos/, thumbnails/)
  • manifest.json with attribution
  • Human approval mode
  • Pause, resume, and rerun
  • Media Library browser
  • Platform targets: YouTube, Shorts, TikTok, Reels
  • Visual style presets: cinematic, documentary, tech, nature, and more
  • Download sandbox and URL validation
  • Dark and light themes
