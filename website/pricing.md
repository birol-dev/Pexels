# Pricing — StockFinder AI

Canonical human-readable page: https://stockfinderai.birol.tech/pricing/

## App license

- **Price:** $0 — free forever
- **License:** MIT open source
- **Subscription:** None
- **Platforms:** Windows, macOS, Linux
- **Download:** https://github.com/birol-dev/Pexels/releases

## What you pay for

StockFinder AI itself has no cost. You bring your own API keys:

### LLM provider (required for AI beat mapping)

- **OpenAI** — pay per token (typically cents per script run)
- **Google Gemini** — pay per token (typically cents per script run)
- **OpenRouter** — pay per token; unlocks Claude, Qwen, and other models

You choose the provider and model. Keys are stored locally in your OS keychain.

### Pexels API (required for stock search)

- **Price:** $0 — free developer API
- **Limits:** Subject to Pexels rate limits (monthly quota tracked in-app)
- **Sign up:** https://www.pexels.com/api/

## Feature availability by tier

There is only one tier — everything is included:

- Script-to-beat AI parsing
- Pexels photo and video search
- Organized local downloads (photos/, videos/, thumbnails/)
- manifest.json with attribution
- Human approval mode
- Pause, resume, and rerun
- Media Library browser
- Platform targets: YouTube, Shorts, TikTok, Reels
- Visual style presets: cinematic, documentary, tech, nature, and more
- Download sandbox and URL validation
- Dark and light themes

## Enterprise / teams

No separate enterprise tier. Fork the MIT-licensed source on GitHub for custom team workflows.
